# AI-Zen CLI

AI-Zen 宿主的终端客户端。一个可执行文件，两种用法：交互界面，与面向脚本的一次性调用。会话、历史与模型配置都在宿主那一侧，客户端只负责连接、渲染与发送命令。

## 装上并连上

```bash
npm i -g @ai-zen/cli
ai
```

`ai`、`aiz`、`zen` 三个名字等价。启动后先到连接屏：选「本机」就在本机启动宿主（没装时先下载），选「远程」就填地址与令牌。地址可以写成 `wss://example.com/ai-zen` 或 `10.0.0.5:8790`，不写协议前缀时按 `ws://`。令牌留空表示用本机宿主的令牌。

```bash
ai --server ws://192.168.1.10:8790   # 跳过连接屏
ai --server-status                   # 打印宿主状态，不拉起、不进界面
```

## 两种模式

同一个进程只走其中一条：

| 调用方式 | 模式 |
|---|---|
| 带位置参数，或 stdin / stdout 不是 TTY | 纯 stdio：一次性调用，stdout 只有助手最终的文本，日志与进度走 stderr |
| 无参数且 stdin / stdout 都是 TTY，或 `--tui` | 交互界面 |

```bash
ai "这个仓库用了哪些构建脚本"     # 一次性，不落库
ai --save "看完 src 后总结一下"    # 一次性，但写成一段真会话
ai --new                          # 进界面，开新会话，不续接这个目录上一次的
```

退出码分三档：`0` 成功；`1` 已经跑起来之后的失败；`2` 命令本身用错（`--tui` 但终端不是 TTY、地址拼错、没有输入）。

## 界面

从下往上：状态栏、输入行、排队区、阶段行、命令与文件候选菜单、通知栏、子代理分栏，其余是会话转录。

日常用到的键：

| 键 | 作用 |
|---|---|
| `Enter` / `Ctrl+J` | 发送 / 换行 |
| `/` · `@` | 命令菜单 · 文件补全 |
| `PgUp` `PgDn` · 滚轮 | 回看历史 |
| `Ctrl+C` | 生成中中断；有草稿时清空输入；空输入时退出 |
| `Ctrl+D` 两次 | 退出程序，宿主继续运行 |
| `Ctrl+S` | 暂存 / 恢复草稿 |
| `Ctrl+V` | 粘贴；剪贴板里是图片就附加到消息上 |
| `Ctrl+X` / `Ctrl+G` | 清本会话通知 / 清全部通知 |
| `Esc` | 输出被暂停时恢复；交接进行中则放弃交接 |

没有 `Alt` 快捷键：它在终端、shell、tmux 与输入法之间表现不一致，应用级动作只落在 `Ctrl` 上。

agent 在跑的时候，输入框仍然可以打字，但只有中止与回看生效；发出去的话进排队区，等这一批跑完再被取走。

## 命令

输入 `/` 打开候选，`/help` 列出全部。常用的：

| 命令 | 作用 |
|---|---|
| `/new` · `/load` · `/sessions` | 新建 · 打开 · 列出并切换会话 |
| `/ws` | 工作区：列出、切换、新建、删除 |
| `/model` · `/think` | 切换模型（会话 / 助手定义 / 全局）· 切换思考强度 |
| `/back` | 撤回上次发言以便修改重发 |
| `/handoff` · `/migrate` | 生成交接文档 · 生成并切换记忆（旧记忆归档） |
| `/free` · `/clear` | 清空排队区 · 清屏 |
| `/config` | 配置中心：端点、模型、助手定义、MCP 服务器 |
| `/reload` | 重新加载工具、技能与 MCP 服务器 |
| `/upgrade` | 升级宿主到发布标签里的最高版本 |
| `/kill` · `/delete` · `/shutdown` · `/exit` | 终止 agent（保留历史）· 删除会话 · 关闭宿主 · 退出程序 |

有一类命令在 agent 跑着的时候会被拒绝：`/model`、`/think`、`/back`、`/handoff`、`/migrate`。它们改的是这一段正在使用的设置，中途换掉会让工具调用的格式对不上。

## 配置

配置分两处：`<数据根>/config.json` 放端点、模型、助手定义（会话、历史与它一起在宿主那一侧），`<数据根>/cli/preferences.json` 只放界面语言。`<数据根>` 由 `AI_ZEN_DIR` 指定，缺省 `~/.ai-zen`。

模型按三级解析：会话覆盖 > 助手定义 > 全局兜底。三级都取不到时报错并指出是哪份定义没绑模型，不会静默挑一个出厂模型。

`/think` 的档位来自端点的思考策略表，表里有哪些档就能选哪些；表里没有关闭项（强制思考的模型）就没有关闭这一档。

## shell 钩子

把「敲错命令」接成「问 AI」：

```bash
ai hook install      # 往 ~/.zshrc 或 ~/.bashrc 写一段 command_not_found_*
ai hook uninstall
```

钩子执行 `ai --tui --new "$@"`：进界面、开新会话、把原命令作为首条消息。不支持 `zsh` 与 `bash` 之外的 shell。
