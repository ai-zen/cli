# 界面

## 空会话时

空会话的转录顶部是品牌块 —— logo、标语、客户端与 SDK / core 的版本。它是转录的普通内容：会随转录滚走，滚回来还能看到。

## 布局

布局吸底。自下而上依次是：

| 位置          | 是什么                       |
| ------------- | ---------------------------- |
| 状态栏        | 五块事实与快捷键提示         |
| 输入行        | 草稿与硬件光标               |
| 分割线        | 底栏与转录的分界             |
| 排队区        | 还压在队里、没被取走的那几句 |
| 阶段行        | 此刻在做什么，一行           |
| 命令菜单      | `/` 命令与 `@` 路径补全共用  |
| 待发图片行    | 这一条消息上挂着几张图       |
| 通知栏        | 通知唯一上屏的地方           |
| subagent 页签 | 存在 subagent 时才出现       |

分割线以上的那几块只在有话要说时出现，剩下的高度全给转录。每一块各自按它那几行计入底栏：阶段行与待发图片行恒为一行，排队区最多三行，通知栏最多八行加一行入口提示。

回看历史用鼠标滚轮、`PgUp` / `PgDn`；有的终端把这两个键留给自己滚，翻页的兜底是 `Ctrl+B` / `Ctrl+F`。

## 状态栏

五块，每一块都在画这一帧时从会话上现取：

| 块     | 内容                                                                            |
| ------ | ------------------------------------------------------------------------------- |
| 身份   | 模型 id、思考强度                                                               |
| 四件事 | 忙或闲；已停止、不取走、不收话各自在不是常态时出现                              |
| 用量   | 这一次回答用的 token 与全部回答的 token 合计，由客户端从每条消息的 `usage` 上算 |
| 速率   | 生成中是实时估算，结束后是这一次回答的平均                                      |
| 快捷键 | 界面自己的提示那一行                                                            |

块是折行的单位：放不下就整块挪到下一行，空块不占宽度。算不出来的那两块整段不占位，不写 0 假装。

## 阶段行

阶段行在分割线之上，Agent 手上有活时才有。它说的是客户端从手上的事实里读得出的那一档 —— 只回答「这一任此刻在干什么」；**队里压着的话不在这里说**，那几句由排队区逐条回显（「排队中 <原话>」）：

| 档           | 什么时候                                 |
| ------------ | ---------------------------------------- |
| 正在交接     | 这一段在写文档或等它收口，盖过下面所有档 |
| 连接中       | 手上已经有活，这一批的消息还没落下来     |
| 等待首字     | 请求已经发出，一条字都还没回来           |
| 思考中       | 思考已经出来，正文还没有                 |
| 调用工具     | 参数还在拼，或者刚拼完                   |
| 等待工具返回 | 工具在跑，几件并行时只念还在跑的那几个   |
| 输出中       | 正文在流                                 |

调工具与等工具回来那两档会念出工具名。整行恒为一行，标签超宽就截断。拦输入框的命令执行时，这一行念的是命令名。

## subagent 页签

存在 subagent 时转录下面多一行页签，每个页签前面的 `◈` 说的是状态：

| 颜色 | 状态           |
| ---- | -------------- |
| 闪   | 在跑           |
| 绿   | 散场           |
| 红   | 失败           |
| 淡   | 被叫停         |
| 暗   | 还挂着，没在动 |

输入框为空时按 `←` / `→` 换一段转录看。页签只换「看谁的话」，不换会话。

## 通知栏

通知栏是通知唯一上屏的地方。它们永远不进消息，于是永远到不了模型。

三档语气：info、warn、error（宿主报的四档折成这三档，成功归普通那一档）。多条通知按到达顺序排在栏里，栏位留最近 4 条、最多 8 行；放不下时从最早的那一条整条让位，不把一条通知劈成两半。

两个清空入口：

| 键            | 清什么                                                        |
| ------------- | ------------------------------------------------------------- |
| `Ctrl+X` | 这一段会话的：本地队列加上带这个会话 id 的 `notice.deleteAll` |
| `Ctrl+G` | 先问一次，再把全部清掉 —— 全局通知与别的会话的也在其中        |

## 输入框

输入框是多行的，最多占 8 行；超出的折行由窗口跟着光标滚动，不把转录挤没。`Enter` 发送，`Ctrl+J`（或 `Ctrl+Enter`）换行；`↑` `↓` 在多行草稿里先走光标，走到首行 / 末行才翻历史。

请求在途时照样能打字：发出去的那一句交给宿主放进排队区，排队区显示还在等的那几条（连同它们自己的「排队中」前缀）；阶段行只说这一任此刻在干什么。

`@` 补全文件路径：

- 候选是宿主为这个项目列出的相对路径（`workspace.files`），扫的是跑会话的那台机器。
- 插进草稿的是路径本身，所以消息仍是普通文本，文件由模型自己用工具去读。
- 补全要替换的是整段 `@token`，所以光标停在 token 中间也补得对；菜单开着时 `Enter` 是补全而不是发送。

图片：

- 转录里的图片一律是占位，终端画不了内联图。占位说得出手里已有的那几样：这一条里的第几张、多大、叫什么。
- `Ctrl+O` 列出这一段里还带着 Asset id 的那些图；选中一张就去取字节（`asset.get`）、写一个临时文件、交给本机默认程序（`open`、`xdg-open` 或 `cmd /c start`）。取字节、写文件、打开三步各自报自己那一种失败。
- `Ctrl+V`（终端报得上来的地方 `Cmd+V` 也行）先问系统剪贴板有没有图片：macOS 走 `osascript`，Linux 走 `wl-paste` 或 `xclip`，Windows 走 PowerShell。有图就挂到接下来那条消息上，没有就按普通粘贴把文字插到光标处。
- 剪贴板文本超过 256 KB 时拒收，不截断。挂上的图片随消息经 `asset.upload` 上去；放不放得下是宿主的规矩，它的拒绝原话上屏。
