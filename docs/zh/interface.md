# 界面

一个终端窗口，从下往上排：输入框贴着底，会话转录占剩下的高度。整帧高度恒等于终端行数——布局先算好行数再渲染，不靠渲染时折行。

## 从下往上

| 位置 | 部位 | 内容 |
|---|---|---|
| 最底 | 状态栏 | 身份、用量、快捷键三块。宽度不够时整块顺延到下一行，不把一块劈成两半 |
| 上一条 | 输入区 | 提示行 + 输入行。提示行随状态变：`Enter 发送 · Ctrl+J 换行 · / 命令 · PgUp 看历史` |
| 上一条 | 排队区 | 还没被 agent 取走的条目，前缀「排队中」，只显示前两条，其余折成「另有 N 条」 |
| 上一条 | 阶段行 | agent 正在做什么 |
| 上一条 | 底部菜单 | 输入 `/` 时的命令候选、输入 `@` 时的文件候选，两者共用这一块 |
| 上一条 | 附加图片条 | 已粘贴待发送的图片张数 |
| 上一条 | 通知栏 | 失败、提示、命令结果。通知不进会话转录，`Ctrl+X` 清本会话、`Ctrl+G` 清全部 |
| 上一条 | 子代理分栏 | 有子代理在跑时出现，按委派分栏 |
| 其余 | 会话转录 | 消息本身，可滚动回看 |

阶段行取值：处理中、连接中、等待首字、思考中、调用工具 `<名称>`、等待 `<名称>` 返回、输出中、正在交接。

状态栏的用量格写三样：`本次 N tok`、`累计 N tok`、`均速 N tok/s`。

## 键位

### 输入

| 键 | 作用 |
|---|---|
| `Enter` | 发送 |
| `Ctrl+J` | 换行 |
| `Ctrl+V` / `⌘V` | 粘贴。剪贴板里是图片就附加到消息上，否则粘贴文本 |
| `Ctrl+S` | 暂存当前草稿；空草稿时恢复 |
| `Ctrl+A` / `Ctrl+E` | 行首 / 行尾 |
| `Ctrl+U` / `Ctrl+K` / `Ctrl+W` | 删到行首 / 删到行尾 / 删到前一个空白 |
| `Ctrl+Backspace` / `Ctrl+Delete` | 删前一个词 / 后一个词 |
| `Ctrl+Y` | 取回刚删掉的内容 |
| `Ctrl+_` 或 `Ctrl+Shift+-` | 撤销上一次输入编辑 |
| `Ctrl+P` / `Ctrl+N` | 上一条 / 下一条历史；菜单打开时改为切换候选 |
| `Ctrl+C` | 生成中：中断本次请求。空闲且有草稿：清空输入。输入为空：退出 |
| `Ctrl+D` | 有草稿：删光标后一个字符。空草稿：连按两次退出 |

### 回看与画面

| 键 | 作用 |
|---|---|
| 滚轮 | 逐行滚动 |
| `PgUp` / `PgDn` | 翻页。部分终端把这两个键留给自己，可用 `Ctrl+B` / `Ctrl+F` 代替 |
| `Ctrl+L` | 清屏（只清画面，不动消息） |
| `Ctrl+O` | 选一张本会话里的图片，交给本机默认程序打开 |
| `Ctrl+X` / `Ctrl+G` | 清除本会话通知 / 清除全部通知（后者要确认） |
| `Esc` | 输出被暂停时恢复；交接进行中则放弃交接并恢复到交接前状态 |

终端支持 kitty 键盘协议时，`⌘[` / `⌘]` 翻页、`⌘;` / `⌘'` 逐行滚动。

没有 `Alt` 快捷键。`Alt` 被终端模拟器、shell、tmux 与输入法抢得太多，同一个组合在两台机器上可能是完全不同的两件事；应用级动作只落在 `Ctrl` 上。

## 忙碌时

agent 在跑的时候，输入框仍然可以打字，但只有两类按键真正执行：中止（`Ctrl+C`）与回看（滚动、翻页）。发出去的话不会丢——它们进排队区，等这一批跑完再被取走。

需要等 agent 空闲的命令（`/model`、`/think`、`/back`、`/handoff`、`/migrate`）在跑的时候会直接拒绝，提示「处理中不可用」：那几条改的是这一段正在使用的设置，中途换掉模型或思考参数会让工具调用的格式对不上。

## 覆盖层

三种浮层盖在会话转录上，都吃同一份布局预算：

- **选择器**：模型、会话、工作区、思考强度、命令候选、文件候选。`↑↓` 选，`Enter` 确认，`Esc` 取消
- **表单**：MCP 服务器要求补参数、交接前问用什么方式。`↑↓` 换格，`←→` 换选项，空格切勾选，`Enter` 提交，`Esc` 关闭。字段类型有文本、邮箱、单选、多选、数字、整数、布尔
- **确认**：清空全部通知、升级宿主这类不可撤销的动作

`/form` 会把每一种表单项都摆出来一次，用来检查渲染与键位。

## 子代理分栏

派出去的子代理在转录上方占一栏，按委派分组，栏里是它自己的消息与工具调用。父的消息始终在主转录里；子代理的 `state` 不并进父的状态，所以「这个 agent 现在是否在跑」始终只有父在回答。

## 与会话转录的分界

通知、命令回执、日志告警都不进消息列表：它们是「此刻发生了什么」，不是对话内容。清掉它们不影响会话；重新连上时宿主的通知表会补齐这段时间的失败与越线记录。
