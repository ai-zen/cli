# 命令

输入 `/` 打开候选菜单，`/help` 列出全部。命令是客户端的事：宿主只有一张方法表，它不知道 `/back`、`/pin` 这些名字。清单只有一份，在 `src/commands/registry.ts`。

## 会话

| 命令 | 作用 |
|---|---|
| `/new` | 新建会话 |
| `/load` | 打开已保存的会话；`--all` 跨工作区 |
| `/sessions`（`/ps`） | 列出会话并切换；`--all` 跨工作区 |
| `/ws` | 工作区：列出、切换、新建、删除 |
| `/pin` | 置顶或取消置顶当前会话 |
| `/rename <名称>`（`/save`） | 重命名当前会话 |
| `/title` | 让模型给这一段重新起一个名字 |
| `/back`（`/revert`） | 撤回上次发言以便修改重发 |
| `/kill` | 终止当前会话的 agent，保留历史 |
| `/delete` | 删除当前会话，消息与素材一并删除 |

`/new`、`/load`、`/sessions`、`/ws` 不会打断正在运行的那一段：换走只是切换视图，原来那段继续在后台跑。

`/kill` 与 `/delete` 的区别是保留与销毁：前者只终止 agent，历史与会话行都在，下次唤醒接着用；后者删掉会话行、消息与素材，不可恢复。

`/rename` 改的是会话行上的名字那一格；`/title` 是让模型读一遍这段对话重新起一个。自动起名只在第一次答完时发生，之后再想要一个由你点名。

## 运行控制

| 命令 | 作用 |
|---|---|
| `/clear` | 清屏（只清画面） |
| `/free` | 清空排队区（尚未发送的消息） |
| `/handoff` | 生成交接文档，不切换记忆 |
| `/migrate` | 生成交接文档并切换记忆（旧记忆归档） |

`/clear` 与 `/free` 是两件事：一个清显示，一个清队列。从前它们是一条命令，现在分开——「画面上少了什么」和「发出去的话还在不在」是两种不同的期待。

`/handoff` 与 `/migrate` 对应交接的两档。前者把文档当一次导出，记忆不动；后者写完就换手，旧记忆成为另一段存档会话。

## 配置与模型

| 命令 | 作用 |
|---|---|
| `/config` | 打开配置中心：端点、模型、助手定义 |
| `/model` | 切换模型：本次会话 / 助手定义 / 全局 |
| `/think`（`/effort`） | 切换思考强度 |
| `/agent` | 设置默认助手定义（只影响新会话） |
| `/key` | 设置端点的 API Key |
| `/mcp` | 管理 MCP 服务器：增删、编辑、启停 |
| `/lang` | 切换界面语言 |

`/model` 有三档作用域，与运行时的三级解析一一对应：

| 作用域 | 写到哪里 | 影响 |
|---|---|---|
| 本次会话 | 会话行的 `modelId` | 只这一段 |
| 助手定义 | 定义的 `modelId` | 这个 agent 之后的所有会话 |
| 全局 | `config.json` 的 `defaultModel` | 没绑模型的 agent 的兜底 |

`/think` 的档位来自端点的思考策略表（`reasoning-presets.json`）：表里有哪些档，就能选哪些档。选「跟随模型默认」等于清掉这一层参数；表里没有关闭项（如某些强制思考的模型）就没有关闭这一档。

`/agent` 与 `/model` 的「助手定义」不是同一件事：前者换的是「新会话默认用哪份定义」，不动当前这段；后者换的是这段会话用的模型。

## 其他

| 命令 | 作用 |
|---|---|
| `/reload` | 重新加载工具、技能与 MCP 服务器 |
| `/upgrade` | 选择发布标签中的最高版本并升级宿主 |
| `/help` | 显示帮助 |
| `/form` | 调试：把每一种表单项都摆出来看一眼 |
| `/editor` | 用外部编辑器撰写长消息 |
| `/shutdown` | 关闭宿主并返回连接屏 |
| `/exit`（`/quit`） | 退出程序，不关闭宿主 |

`/upgrade` 升的是宿主，不是客户端：它向发布标签查最高版本、比版本、确认，然后让宿主记录下次启动的版本并以升级为由退出；装包与拉起交给启动方式。这期间本机其他客户端（含桌面端）会断开。会话与历史在数据库里，重启后还在，但正在跑的那一次请求会被中断。

`/reload` 在能力目录里加了文件、或改了 `mcp.json` 之后用。宿主侧的自动刷新由 `autoRefreshTools` 决定；取值为 `off` 时就只有这一条命令能让新能力生效。

## 两类命令属性

命令表里给每条命令标了两个属性，涉及它的行为：

- **需要空闲**（`/model`、`/think`、`/back`、`/handoff`、`/migrate`）：这一段正在跑时直接拒绝，提示「处理中不可用」。它们改的是这段会话正在使用的设置，中途换掉会让工具调用的格式对不上，或者宿主当场拒绝
- **阻塞输入**（`/title`、`/handoff`、`/migrate`）：执行期间宿主要调用模型，几十秒。这期间输入框被拦住，否则你以为没反应、继续打字，按键会被静默吞进隐藏缓冲

两条都是命令自己的属性，写在命令表里，不是宿主的白名单：新增命令只改那一个文件，行为自动跟上。
