# AI-Zen CLI 文档

`@ai-zen/cli` 是 AI-Zen 宿主的终端客户端。文档按「连上、看懂界面、记住命令、改配置」的顺序排。

| 页 | 讲什么 |
|---|---|
| [快速开始](getting-started.md) | 安装、连接屏、两种运行模式、第一句话、退出与退出码 |
| [界面](interface.md) | 从下往上各部位、全部键位、忙碌时的行为、三种浮层、子代理分栏 |
| [命令](commands.md) | 28 条命令按用途分组；两级作用域；两条命令属性 |
| [配置](configuration.md) | 配置中心、模型三级解析、思考强度、两条阈值、MCP、语言 |
| [管道与钩子](pipeline.md) | 一次性调用的输出契约与退出码；shell 钩子 |
| [故障排查](troubleshooting.md) | 连不上、命令被拒、能力不生效、按键没反应、日志、升级 |

客户端不调用模型，也不存会话：会话、历史、模型配置都在宿主那一侧。那部分见 `@ai-zen/agents-host` 的文档。
